# Raio X do Relatório — como funciona

*Resumo para mostrar ao cliente · atualizado em 25/11/2026 14h20*
Versão completa e bonita: https://claude.ai/artifact/YC4rkfD15q4YgNCXoh6KSE

**Em uma frase:** O Raio X do Relatório lê relatórios de ordens de serviço (CSV, Excel e PDF) e monta sozinho o painel e os relatórios que a pessoa escolher. Funciona no navegador, sem API e sem custo por uso, e serve para qualquer cliente.

## Como funciona, em 5 passos
1. **Abra o link** no celular ou no computador (dá para instalar como app e usar sem internet).
2. **Escolha os arquivos** (CSV hoje; planilha Excel e PDF depois). Pode mandar vários de uma vez.
3. **O Raio X reconhece o relatório.** Se for um formato novo, pergunta uma vez "esta coluna é o quê?" e aprende.
4. **"O que você quer acompanhar?"** Aparece uma lista só com o que dá para calcular com os seus dados, já com o número de exemplo. Você marca, e cada item vira um quadro no painel.
5. **Peça por escrito** o que faltou ("OS concluídas por técnico em outubro"). O Raio X mostra "É isso?" com a prévia; você confirma e o quadro entra.

## Depois
- **Editar layout:** arraste os quadros, crie abas, mude o tamanho e o tipo de gráfico.
- **Relatório em Excel** do jeito que está na tela, com capa, período e filtros.
- **Histórico:** cada arquivo novo se junta aos anteriores; dá para comparar mês com mês e ano com ano.
- **Clique em qualquer número** e abre uma janela com os registros por trás dele, para imprimir ou copiar.

## Onde ficam os dados
Só no seu aparelho. Não há servidor nem login. Para levar para outro aparelho, use "Fazer backup" e "Restaurar".

## Modelo pronto: Ordens de serviço
Para manutenção já vem pronto: dashboard do mês, backlog com tratativas, % de atendimento com meta de 90%, tempos até o 1º atendimento, equipe e homem-hora, OS repetidas e "para arrumar".
